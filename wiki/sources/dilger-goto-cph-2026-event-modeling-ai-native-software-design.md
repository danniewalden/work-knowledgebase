## Summary

Dilger's [[event-modeling]] + AI pitch, reduced to a conference abstract: *"AI can generate code in
seconds. Maintaining and evolving that code is becoming the real challenge."* Two days of modelling a
real system, generating code from the model with AI, and *"practical techniques for handling change."*
Topics: Event Modeling foundations; **slicing and architectural boundaries**; AI-assisted software
generation; [[event-sourcing]] principles *"where they provide value"*; designing for change and
long-term maintainability. Audience: architects, engineering leaders, senior developers.

## Key points

- **The framing is maintenance, not speed** — *"From Requirements to Maintainable Systems."* Worth
  noting because it is the one place Dilger's public positioning lines up with
  [[dilger-spec-driven-development-needs-four-phases|his own phase 4]] (Code → Operations &
  Maintenance), which he calls one of the two hardest phases and which **no captured source in this KB
  addresses substantively**. The abstract asserts the frame; it does not fill the hole.
- **The deliverable is the Triplet.** Event Modeling (plan) + slices (structure) + Event Sourcing
  (store), applied *"where they provide value"* — a softer statement of
  [[dilger-triplet-flexible-agent-enabled-architecture|"only pay off when you use all three
  together"]].
- **Speaker byline: *"Agentic Software Modeling on Eventmodelers.ai"*** — the commercial platform
  ([[eventmodelers-ai]]) named in the speaker credit.
- **Programme context, recorded in the capture's own note and useful as an ecosystem reading.** On the
  same days GOTO CPH has scheduled [[adam-tornhill]]'s *"When AI Meets Technical Debt: Evolving Software for
  Humans and Machines"* (Tue), [[alberto-brandolini]]'s two-day *EventStorming Master Class* (Mon–Tue),
  Cole Medin's *"Agentic Engineering - The New Software Development Lifecycle"* (Tue) and Sam Newman's
  *"Modernising Architecture For AI And More"* (Mon, sold out).
  **Dilger and Tornhill — the batch's strong-form-SDD advocate and its sharpest sceptic — are billed on
  the same programme in the same week**, and Event Modeling and [[event-storming]] were sold as adjacent
  two-day masterclasses by their respective figureheads.
