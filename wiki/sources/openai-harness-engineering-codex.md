# Source: OpenAI — Harness Engineering (Codex in an Agent-First World)

Engineering post by Ryan Lopopolo, [[openai]], published 2026-02-11. The widely-cited **origin
case study** that popularised the term "harness engineering." Raw capture:
`raw/articles/openai-harness-engineering-codex.md`.

## Summary

A 3→7-engineer team built and shipped an internal product — ~1M lines of code, ~1,500 PRs, 3.5
PRs/engineer/day — with **zero manually-written code**, all generated by Codex. The constraint
forced them to discover what changes when an engineering team's job is no longer writing code but
"designing environments, specifying intent, and building feedback loops." Slogan: **humans steer,
agents execute.**

## Key points

- **Redefined engineering work** toward systems, scaffolding, leverage. When the agent failed,
  the fix was never "try harder" but "what capability is missing, and how do we make it legible
  and *enforceable*?"
- **Repository knowledge as system of record.** The "one big AGENTS.md" failed (context is scarce,
  too much guidance becomes non-guidance, it rots, it's unverifiable). Instead AGENTS.md is a
  ~100-line **table of contents** pointing into a structured `docs/` tree — enabling
  **progressive disclosure**. Enforced mechanically by linters/CI + a "doc-gardening" agent.
- **[[agent-legibility]] is the goal.** "Anything the agent can't access in-context doesn't
  exist." Push Slack threads, design rationale, tacit knowledge into versioned repo artifacts.
  Favour "boring", composable, API-stable tech the agent can model; sometimes reimplement deps.
- **Enforce invariants, not implementations.** Rigid layered architecture (Types→Config→Repo→
  Service→Runtime→UI; cross-cutting via Providers) enforced by **custom linters + structural
  tests**. Lint error messages are written to inject *remediation instructions* into agent context.
- **Throughput changes merge philosophy:** minimal blocking gates, short-lived PRs, flakes fixed
  with reruns — because corrections are cheap and waiting is expensive at agent throughput.
- **Entropy & garbage collection.** Agents replicate existing patterns → drift. Manual Friday
  cleanup ("AI slop") didn't scale; replaced by encoded "golden principles" + recurring background
  Codex tasks that scan, grade, and open auto-mergeable refactor PRs. Pay debt down continuously.
- **Self-driving features:** the repo crossed a threshold where one prompt drives reproduce→fix→
  validate (with before/after videos)→PR→respond to review→merge, escalating to humans only for judgment.
- Conclusion: "Our most difficult challenges now center on designing environments, feedback loops,
  and control systems."

## Connections / contrast

The **builder/practitioner** counterpart to [[fowler-bockeler-harness-engineering]]'s mental
model — custom linters with remediation messages are exactly Böckeler's "computational sensors
optimised for LLM consumption." Garbage collection + doc-gardening = continuous drift sensors.
Ralph-loop review (see [[ralph-loop]]) and progressive disclosure overlap with
[[langchain-anatomy-of-an-agent-harness]] and [[anthropic-effective-harnesses-long-running-agents]].
