# Append-and-Review Note

A note-taking method from [[andrej-karpathy]]
([blog post](https://karpathy.bearblog.dev/the-append-and-review-note/)): maintain
**one single text note**, no folders or tags, where `Ctrl+F` is the only search needed.

## Mechanics

- **Append** — any idea, todo, or link gets added to the **top**, as plain text.
- **Gravity** — as new items land on top, older ones sink toward the bottom.
- **Review** — periodically scroll down and skim; rescue what still deserves attention
  by copy-pasting it back up, merging related notes. Things that don't earn attention
  keep sinking. Notes are rarely deleted, never lost.

Optional tags for skimming: `watch:`, `listen:`, `read:`.

The value: once something is captured, you can clear working memory and refocus,
trusting you'll revisit it on review.

## Relation to the wiki
