# Adaptech Group

Software development company founded and led by [[adam-dymitruk]], where
**[[event-modeling]]** was developed (adaptechgroup.com).

## Notes

- Offers **fixed-price** software delivery, which Dymitruk credits to event modeling's
  flat cost curve — counting state changes and projections makes scope and price visible
  up front, so projects aren't "late, over budget, or delivered incomplete."
- Practices [[event-sourcing]] and vertical slicing as its build approach.
- **Design writing (2026-07-28):** published *Your Workflow Should Not Live Inside a Giant Process
  Manager* ([[adaptech-workflow-not-inside-giant-process-manager]]) — replace a large saga/process
  manager with a **projected to-do list + focused single-responsibility processors**; the worked
  primary for [[process-managers-and-todo-lists]] and Event Modeling's Automation pattern. States
  Event Modeling is treated as a **foundation for Event Sourcing work** at Adaptech.
