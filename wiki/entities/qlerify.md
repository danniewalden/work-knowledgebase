# Qlerify

An online **[[event-modeling]]** tool (Qlerify AB; a Techstars portfolio company) that uses LLMs to
generate event models — and code — from a plain-language workflow description. In the KB it is the
source of a hands-on AI-assisted Event Modeling walkthrough ([[qlerify-event-modeling-tool-ai]]).

Relevant to [[event-modeled-agent-design]] as evidence of the AI × Event-Modeling intersection from
the tooling side: it automates event/command/read-model/Given-When-Then
drafting across [[adam-dymitruk]]'s seven steps, treats **Automation as an actor**, and slices GWT
scenarios into releases. Vendor source — productivity claims are self-reported.
