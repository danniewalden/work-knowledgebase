# Yordis Prieto

Polyglot software engineer (Principal-level) focused on **distributed systems, event-driven
architecture, event sourcing, and CQRS** — self-described as optimizing "for the lowest common
denominator," removing code and complexity "until there is nothing left to remove"
(yordisprieto.com). Named by **[[adam-dymitruk]]** (alongside **[[martin-dilger]]**) as one of
"the best way to achieve" assembling best-practice systems with AI agents
([[dymitruk-ai-trained-on-dysfunction-agents-are-a-must]], 2026-06-15). No longer a pure
watch-list stub — his own writing is now captured.

## Position (from his own writing)

- **"Code is the source of truth; diagrams are throwaway discovery tools."**
  ([[yordis-prieto-code-is-the-ultimate-diagram]], 2026-07-02) — diagrams are worth most early,
  cheap and discarded; they decay the moment code is written; regenerate the picture *from* the
  code, and when picture and code disagree, the code wins. This is a **direct counter-position**
  to the Event-Modeling "model is the living spec / source of truth" camp — see the contrast with
  [[dilger-is-code-still-the-source-of-truth]] noted on the source page and in
  [[event-modeled-agent-design]]. Notably Dymitruk endorses *both* Prieto and Dilger despite this
  tension, suggesting he values the shared "regeneration over stale artifacts" instinct over which
  artifact is primary.
- **ES/EDA practitioner surface:** recent writing covers the **Outbox pattern** (2026-04-08) and the
  **Claim-Check pattern** (2026-03-30, with an interactive widget); active work on agent runtimes
  (an ACP ⇔ NATS.io bridge) and on feeding open-source repo/PR/workflow context into coding agents.
