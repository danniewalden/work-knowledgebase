# John Wilger

Software developer and author of the open-source **`jwilger/agent-skills`** repository
([[jwilger-agent-skills-event-modeling]]) — a CC0-licensed set of portable [Agent Skills](https://agentskills.io)
that teach AI coding agents a disciplined SDLC (TDD, domain modeling, **[[event-modeling]]**, code
review, ADRs) plus an "ensemble team" and an autonomous **factory pipeline**.

In the KB he matters as a practitioner pushing [[event-modeled-agent-design]] from assertion toward
practice: his `event-modeling` skill turns the method's output (vertical slices + Given-When-Then
scenarios) into the contract that drives [[unattended-coding-agents]] through [[harness-engineering]]
quality gates — bridging the Event-Modeling and harness threads. Not otherwise affiliated with
[[adam-dymitruk]] / [[adaptech-group]] or [[prooph-board]] as far as the captured source shows; this
is an independent third-party adoption of Event Modeling for agent workflows.
