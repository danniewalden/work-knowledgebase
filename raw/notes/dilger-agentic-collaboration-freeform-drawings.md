This starts to feel like true agentic collaboration.

Today I added a genuinly useful tool to the Event Modelers Plattform. As usual, it started as an experiment..

Besides the structured Chapters, which guide you in your Modeling using an Excel-like structure, there´s now the additional "free form drawings".. I didn´t realize how much potential that brings.

The whole experiment quickly turned into an "wow" and then a "Wait, what?"

First I started by drawing myself.. then I started drawing using the Voice Mode.. just using my voice.. then I drew a line around a group of nodes and put a question inside - "Does this make sense?"

Turns out, the agents read the drawings and have the context as well.. what´s inside, what´s outside. Where does an Arrow point to?

The true magic really happened when I added the MCP tools to give the agent the ability to draw itself. Combining that with my favorite "WDYT?" ( what do you think - skill ) that asks the agent to review and comment on the model - results not only in comments now, but also in sketches, arrows, question marks and written text-questions..

It really starts to feel like having a colleague somewhere remote joining the Board and just working with you.
Drawing somethings, sketching some thoughts..

WDYT?
