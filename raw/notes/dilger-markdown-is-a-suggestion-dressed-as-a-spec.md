Writing Code by hand is so 2024.

It´s ridiculous we´ve chosen Markdown as the "language" for LLMs.

I keep watching engineers explain, in great detail, how something should work.

Most of the time it´s close to begging.

Paragraph after paragraph of markdown, trying to get an agent to do what it's told. Oftentimes the description is longer than the resulting code.

Pages of prose to produce a handful of lines. If the explanation outweighs the thing it's explaining, the tool doing the explaining is wrong - always was.

We have a formal language - it´s called Code.

Now everybody is shying away from it, nothing gets written by hand anymore.

The Markdown we use is a suggestion dressed up as a spec. There is only one thing worse than written specifications - spoken ones. Both fail the spec-test if the used language is wrong.

Spec-Driven Development requires suitable language. Event Modeling is the one that works for me.

A precise specification of behavior.

Stop playing with your agents. Go back to work. Stop writing prose, use a suitable language. Back to engineering please.
