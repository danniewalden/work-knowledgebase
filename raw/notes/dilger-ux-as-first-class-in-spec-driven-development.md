More and more people discover the Power of UX for Spec Driven Development

There is a reason we've made this a first class citizen in our Spec-Driven Development Workflow based on Event Modeling.

We are doing this for years - because it works. With humans and AI.

Instead of deriving the UX from markdown files ( which become unreadable and impossible to maintain from a certain size on ), we focus on the functionality, the UX and the business rules described as Given / When / Then ( BDD Style )

Spec-Driven Development does not need Markdown Files.
