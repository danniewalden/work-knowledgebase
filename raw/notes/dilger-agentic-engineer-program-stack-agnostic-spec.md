The Agentic Engineer is starting next week.

It's my 3 week program, that teaches you step by step how to build an agentic Spec-Driven Development Pipeline.

Participants will have their first implemented Slices by the end of Week 1 ( fully specified using Event Modeling ) - built with Event Sourcing and Vertical Slices.

And before you ask - the Implementation-Stack itself almost doesn't matter. Participants can pick one of the many Build Kits available - #axon, #marten, #cratis, #emmet (node) , #python ( or simply build one for their own stack of choice )

Fully taking advantage of the "Spec" in Spec-Driven-Development - they can even switch stacks mid-course or build in parallel in all Stacks.

There are some rules:
- Participants will model every single day ( thus getting into the habit of Software Modeling )
- They'll learn the ins- and outs of applying Event Modeling to a real world project
- Each participant own a dedicated board - but fully visible by all other participants. Multiplying the learning-effect - see how others model and even start to model together.

Each participant gets a 12-month License for EM-Studio - the agentic Event Modeling Plattform ( yes, also commercially usable ) - and also access to my Book "Understanding Eventsourcing" and early access to my new book "Spec Driven" ( release October 16 )

The September-Cohort is sold out, but I just opened registrations for the October-Cohort starting October 05 ( if you register before September 07, you'll get it for the Price of the September Cohort and save 160 EUR - just use Code AGENTIC102026 ) - find the links in the comments.

The program is als available as an In-House Training for Software Teams ( includes a 12-month Enterprise License for EM Studio - also hostable on-premise )

I'm super proud of this program, it includes everything I learned in the last 5 years ( and I had to work hard to learn this stuff ). I can't wait to kick this off.
