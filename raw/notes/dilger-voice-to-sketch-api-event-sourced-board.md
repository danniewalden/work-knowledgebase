Software Modeling with Event Modeling is fun!
( testing the new voice to sketch API on the Eventmodelers Plattform, using Qwen3.6:27B and Claude Code behind vLLM )

"Hey Claude, can you place 3 chapters 1,2,3 - 1,2 in a row, 3 below centered between them. add 3 commands each in A2,B2 and C2.
Also add a feedbacklane in chapter 3, place red feedback nodes in each cell. Then draw a red heart around all 3 chapters and write in bold letters "Happy Weekend". Finally place 3 beers right to that"

And before drawing, Claude was so kind to check the Board History to make sure nobody will blame it later - " I need to flag something before continuing: the board's event history shows that right after our last round of edits, everything got deleted. I didn't issue those deletes myself." - good we are event sourced 🫢

For sure the best 14k tokens I spent today. Happy Weekend.. 🕶️
