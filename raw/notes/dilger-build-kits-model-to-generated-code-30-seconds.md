"From Model to generated Code in 30 seconds"

that´s my idea for the build kits.. and I´m dead serious about this.

When I started learning Event Sourcing - there were just a handful of articles, but zero.. literally zero real world examples.

I was so annoyed.. why can´t just someone show mit how that works?

Now the vision slowly becomes reality. Just today someone reached out to me, zero experience with Event Sourcing so far but had just built 2 slices following the instructions how to model - and then handing them over to an agent to build them.

I´m not saying this should be deployed to production immediately - but what I´m saying is - by seeing the system modeled being built following best practices - the learning happens 10x faster.

Now you can just iterate, change the model, see how that impacts the implementation.. that´s how people learn.. and later build.

I had to put the pieces together by hand, one by one. It took ages. Now people start to build event sourced systems in no time.. I´m just waiting for them to discover how easy they are to maintain..

Want to adopt one of those built-kits? Let me know - happy for contributions to this.
