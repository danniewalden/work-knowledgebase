The Eventmodelers Plattform now officially supports the Event Sourced Domain Modeling Language (ESDM)

I chatted with Golo Roden at the Event Modeling Conference in Munich a few weeks ago after he gave a talk about ESDM.

The plattform always had it´s own well-documented format used for years in tool support. But it was always clear I wanted it to be open to any format.

Yesterday I added the possibility to export any Event Model to ESDM via the UI, but also via API, MCP and the CLI.

So your agent can request any modeled slice or chapter in the format it needs.

It took less than an hour to add the support - the whole plattform is an extension model. Literally anything is an extension - supported languages, supported datastores, anything. So it´s very easy to add new functionality.

I´ll be working with Golo on an Event Modeling Extension for ESDM to better support the notion of the timeline used in Event Modeling.

I added some examples how to get started in the documentation: https://lnkd.in/ddgSb4-K
