3. **Dilger — "Are you using Draw.io for Event Modeling?" (model-in-code, AI manipulation, MCP guardrails)** — *filed, not yet ingested.* `raw/notes/dilger-drawio-event-modeling-model-in-code.md`
   **TLDR:** Dilger endorses keeping the model in the repo ("we need the model in the code") but lists Draw.io-XML's drawbacks (opaque to non-technicians, no framework/rules for the AI, not directly readable), and pitches the alternative: export to a standardized JSON, version it in git, let a local agent manipulate it via provided skills, and use an **MCP endpoint to validate changes before commit** so the agent gets guardrails and self-corrects.
