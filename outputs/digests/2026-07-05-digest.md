**2. Dilger — Local-LLM distributed agent setup (2-part LinkedIn series), ~2026-07-02**
`raw/notes/dilger-local-llm-distributed-agent-setup-event-modeling.md` — *filed, not yet ingested*

**3. Dilger — "My Wife Asked Me to Build a Registration Form for a Flea Market," ~2026-07-01**
`raw/notes/dilger-flea-market-model-code-deploy-30min.md` — *filed, not yet ingested*

**4. Dilger — "Are you using Draw.io for Event Modeling?" (model-in-code, MCP guardrails), ~2026-06-30**
`raw/notes/dilger-drawio-event-modeling-model-in-code.md` — *filed, not yet ingested*
- **TLDR:** Dilger agrees with clients who want "the model in the code" and keep draw.io XML in the repo, but names the drawbacks (non-technicians can't contribute; AI has "no framework, no rules" so it errs; XML isn't directly readable; uncommitted = doesn't exist). His alternative: export to a standardized JSON, version it in git, let a local agent manipulate the JSON via provided **skills**, and use the **MCP to validate changes before commit** so the agent gets guardrails/feedback and self-corrects. Supports code-gen via Build-Kits (Node/Java/Kotlin).
- **Why it's worth reading:** Directly on the model-in-repo + agent-harness-guardrails threads — the "give the agent a validating MCP, not just a prompt" pattern echoes Tornhill's deterministic-sensor argument.

**5. Dilger — "Extending Event Modeling: an optional 'Query' (WHEN) on the read side," ~2026-06-29**
`raw/notes/dilger-extending-event-modeling-query-when.md` — *filed, not yet ingested*
- **TLDR:** Dilger's first-ever deviation from the EM "standard": adding an **optional `WHEN` named "Query"** to the read side of Given/When/Then. Previously read-side scenarios were GIVEN event → THEN expect data; now GIVEN event → WHEN we query by X → THEN expect Y. Driven by repeated independent feedback at the Munich conference (and a prior discussion with Dymitruk); he frames it cautiously and as feedback-sought, not unilateral.
- **Why it's worth reading:** A rare change to the EM notation itself, straight to your `[[given-when-then]]` concept — worth capturing precisely because Dilger is usually a strict standard-keeper.
