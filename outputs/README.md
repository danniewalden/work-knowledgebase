# outputs/ — Finished deliverables

When you ask a question and the answer is worth keeping — a comparison table, a
synthesized report, a slide deck, a chart — it gets filed here instead of
disappearing into chat.

The rule of thumb:

- **Knowledge** (durable facts, connections) → goes into `wiki/` as a page.
- **A deliverable** (a report, deck, table, or chart someone reads once) → goes
  here in `outputs/`.

Anything here can be regenerated from the wiki, so treat it as disposable build
output rather than source of truth.
